## 阶段 0：定主轴 = 热点二创（已定）

用户决策：从零冷启动，主轴采用"热点事件/热点视频 + 自己的二次创作（转换）"。这比固定垂直更适配冷启动抓流量——热点本身是流量入口，"转换"是差异化手段。

**每日热点筛选标准（只做符合的）**
- 调性契合：宠物 / 情感共鸣 / 生活感悟 / 轻知识 优先；国际政治、严肃灾难、敏感话题不碰
- 时效窗口：热点爆发后 **24–72h** 内必须发，过期流量归零
- 可"转换"：你能在其中安插自己的真实角度/素材，而非纯搬运

**二创"转换"的 4 种套路（避免非原创限流）**
1. **角度反转**：「大家都说 X，但我看到的是 Y」
2. **情感落点**：热点 → 讲一个你自己的相关真实故事
3. **知识增量**：热点事件 → 补一个被忽略的常识/数据（需准确，不编）
4. **形式重构**：原视频横屏/口播 → 你做成图文卡点 / 第一人称 vlog

> ⚠️ 纯搬运/简单剪辑会被判定非原创而限流，"转换"必须是真实差异化。

## 阶段 1：冷启动填充（0–4 周）

目标：**建立可观测的发布→数据→复盘闭环**，拿到指标基线。

- **发布频率**：每周 ≥ 3 条（热点为主，1 条日常保底）
- **热点二创选题**：从文末「今日热点弹药」挑调性契合的，按 4 套路之一转换
- **日常保底选题**（无热点时的高完播结构模板，素材需你替换为真实内容）：
  1. 【反常识开场】"你以为 XX，其实…" + 30 秒一个具体反例
  2. 【痛点共鸣】"XX 的人真的会崩溃" + 你自己的真实场景
  3. 【清单体】"做 XX 前必看的 3 件事" + 每条一个画面
  4. 【观点输出】"我不建议 XX，因为…" + 一个强立场
- **每条必盯 3 指标**：2 秒跳出率（目标 < 50%）、完播率（目标 > 25%）、互动率（赞+评+转 / 播放）
- **发布前检查**：标题含痛点/数字/疑问句其一；封面有真人脸或强对比文字；话题挂 1 主 + 2 长尾；发布时间 12:00 / 18:00 / 21:00 三选一测流量

## 阶段 2：数据驱动优化（1–2 月）

- 每周复盘：哪类"转换"套路 2 秒跳出率最低 → 固化为模板；哪类完播高 → 加时长；哪类互动高 → 加引导
- 单变量实验：每次只改一个（钩子 / 封面 / 时长），不混改
- 目标：单条播放量较基线提升一个量级，2 秒跳出率持续下降

## 阶段 3：冲热度飞轮

- 出现万级播放单条 → 追同结构 3 条测试可复制性
- 净增粉丝转正并持续 → 引入合集/系列化，抬升关注转化

## 附 B：二创脚本示范（结构模板，素材请替换为你的真实内容）

**示范 A — 情感落点型（基于 #小狗疑被毒死女子辞职追凶3年#）**
- 0–3s 钩子：「一个人为一只狗辞了职、追了三年，你觉得疯了吗？」
- 3–20s 反转：「我反而觉得她清醒——有些人弄丢的，是一辈子的陪伴」
- 20–35s 落点：讲你自己的宠物/信任观（真实素材）
- 结尾：提问引导评论「你为谁拼过命？」

**示范 B — 知识增量型（基于 #我国打破核电对铀的依赖#）**
- 0–3s 钩子：「中国核电以后可能不再卡脖子，但原因不是你想的那个」
- 3–25s 增量：用 1 张图口语化讲清"钍铀转换"是什么，不堆术语
- 结尾：劝追热点别只喊口号，懂点原理才站得住

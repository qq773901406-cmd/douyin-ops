## 拍摄 / 剪辑提示（二选一）

**A. 无真人出镜版（推荐冷启动）**
- 素材：1–2 张小狗照片 + 新闻标题截图 + 纯色/模糊背景
- 工具：剪映「图文成片」或 CapCut 自动字幕，配悬疑 BGM（如《悬疑感纯音乐》）
- 成本：30 分钟内出片，零拍摄

**B. 真人出镜版（涨粉更强）**
- 前 3 秒怼脸问句：「你愿意为一只狗，辞掉工作吗？」
- 中段手持手机展示新闻截图，增强真实感
- 结尾正对镜头抛问题，引导评论

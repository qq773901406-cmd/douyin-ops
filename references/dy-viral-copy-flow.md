# DY Viral Copy 链路（URL 输入）

目标：输入一条爆款视频 URL，输出"高贴合主题"的可发布新内容（封面方案、标题、文案/脚本、话题）。

## 标准四步流程（默认）

1. 输入爆款视频 URL
2. 分析爆款因素（标题/封面/文案/互动/视频结构）
3. 参考封面图，用 Nano Banana 2 生成新封面（默认 style-only）
4. 发布（上传视频/图文、填写标题文案，发布前确认）

## 1) 输入

- `source_url`：爆款视频链接
- `copy_mode`：`style-only`（默认）| `tight`（高一致性）| `medium`（中贴合）

默认使用 `style-only`：保留原主题与互动机制，但封面只参考风格/色调/信息层级，不复用具体元素。
仅在用户明确要求"高一致性复刻"时才切换 `tight`。

## 2) 源视频拆解（必须）

提取并记录：
- 标题模板：年份/动作词/情绪词/句式
- 封面模板：主文案、信息层级、配色、封面文案位置
- 文案/脚本模板：前3秒钩子、正文展开段数、结尾CTA
- 视频结构模板：钩子→展开→证据→收尾的节奏
- 互动模板：评论区动作词、参与门槛
- 标签模板：核心话题与长尾话题
- BGM模板：BGM类型、节奏、与内容配合方式
- 视频时长：参考时长范围

封面抓取规则：
- 优先从 `meta[property="og:image"]` 的 `content` 属性获取封面 URL
- 兜底：从 `<video>` 元素的 `poster` 属性获取
- 取到 URL 后下载转存为 PNG/JPG，用于生图输入。

输出 `Source Template`（简短结构化）。

## 3) Viral Copy 改写规则（tight）

目标：像同一题材下的"第二篇爆款"，而不是跨主题 remix。

- 保留：
  - 同主题（不改主议题）
  - 同互动机制（如"评论区打确认"）
  - 同内容结构（标题风格、视频节奏、封面层级）
  - 同视频时长范围
- 替换：
  - 具体措辞、案例细节、表达顺序
  - 账号人设口吻（轻量注入，不改主题）
  - BGM选择（避免完全相同的BGM）
- 禁止：
  - 逐句照抄
  - 原视频/原图二次使用
  - 原作者专属信息/隐私迁移
  - 使用完全相同的BGM（版权风险）

封面一致性控制（关键经验）：
- 当图生图结果"元素一致性过高"时，立即改为"style-only"提示词：
  - 仅参考风格、色调、信息分层与竖版构图
  - 明确禁止复用：人物姿势、图标组合、文本框形状与位置
- 使用"保留主题 + 重设计元素"策略，不要求元素一模一样。

## 4) 输出格式（一次给全）

1. 标题/文案：3 个（其中 1 个 <=20 字）
2. 视频/图文描述：1 版可直接发布
3. 前3秒钩子方案：2 个备选
4. 封面：
  - 主文案 + 副文案
  - 1 条生图 prompt（高文字可读）
5. 配图（图文模式）：3-6 张图解文案 + 对应 prompt
6. 话题：5-8 个
7. BGM建议：类型/风格描述

## 5) 发布衔接

调用发布流程：`references/dy-publish-flows.md`

- 视频上传（如有视频文件）：走标准上传流程（`dy-openclaw-browser-guide.md` §3）
- 或图文上传
- 填标题文案
- 发布前停在按钮处确认

## 5.5) 发布前相似度自检（必须执行）

在进入发布流程之前，必须对生成内容与源视频做一次结构级相似度自检，防止内容查重判定为"搬运"。

### 检查维度

| 维度 | 检查方法 | 阈值 | 超阈值处置 |
|---|---|---|---|
| 标题句式 | 对比标题骨架是否同句式 | 同句式 ≤ 1 处 | 改用备选标题骨架 |
| 文案段数 | 对比文案段数和各段功能 | 段数差距 ≤ 1 | 调整文案结构 |
| 前3秒钩子 | 对比开头1-2句是否同义 | 完全同义 = 不通过 | 重写钩子 |
| CTA 措辞 | 对比互动引导词是否相同 | 完全相同 = 不通过 | 换一种互动问法 |
| 话题重合 | 对比话题标签组重合度 | 重合 > 60% = 不通过 | 替换 2-3 个话题 |
| 视频结构 | 对比视频节奏结构 | 完全相同 = 不通过 | 调整展开顺序 |

### 检查流程

```
1. 读取 Source Template（§2 中拆解的源视频模板）
2. 逐维度对比生成内容与源模板
3. 记录每个维度的相似度结果
4. 如果有 2 个以上维度超阈值 → 整体不通过
5. 不通过时自动调用备选方案：换标题骨架 + 重写钩子 + 替换话题
6. 重新生成后再次自检，最多 3 轮
7. 3 轮仍不通过 → 提示用户手动调整后再发布
```

### 自检结果记录

```yaml
similarity_check:
  source_url: "https://www.douyin.com/video/..."
  check_round: 1
  dimensions:
    title_pattern: pass
    body_structure: pass
    opening: fail
    cta: pass
    tags_overlap: pass
    video_structure: pass
  overall: fail
  action: "已重写前3秒钩子，第 2 轮通过"
  final_status: pass
```

### 与反封号衔接

- 相似度自检通过后，还需确认账号健康度为"健康"或"观察"（参见 `dy-anti-ban-rules.md` §3）。
- 如果账号健康度为"限流"或"异常"，禁止执行 Viral Copy 发布。
- 发布频率需符合当前账号阶段的日上限（参见 `dy-publish-cadence.md`）。

## 6) 风险与合规

- 不承诺"必爆/保证涨粉"
- 不输出违规医疗、夸大承诺、引战内容
- 使用"结构级复刻"，避免"文本级抄袭"
- 抖音对搬运内容检测严格，Viral Copy 生成的是新内容而非搬运
- 视频内容如涉及音乐版权，建议使用抖音热门BGM库中的音乐

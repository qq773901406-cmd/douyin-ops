# DY 创作后台真实数据复盘

用于确认已发布视频与账号表现。适用场景：用户要求"确认视频数据""看发布后真实数据""分析账号概览/内容分析/粉丝数据"。

## 0. 原则

- 真实发布状态以抖音创作服务平台后台为准，不以本地草稿、排期表或内容文件为准。
- 分析优先用文本 `openclaw browser snapshot` / `openclaw browser evaluate` 提取，避免截图 OCR，节省 token。
- 后台只读数据属于低风险操作；仍需使用内置浏览器 profile=`openclaw`，登录态丢失时提示用户手动登录，不收验证码。
- 抖音创作后台地址：`creator.douyin.com`

## 1. 进入路径

1. 打开 `https://creator.douyin.com/`。
2. 若进入登录页，停止并请用户在浏览器中手动登录；不要索要短信验证码。
3. 先进入「内容管理」确认已发布列表。
4. 再进入「数据看板」并依次读取：
  - 账号概览
  - 内容分析
  - 粉丝数据

每次点击菜单后必须重新 `openclaw browser snapshot` 校验页面已切换；元素 ref 失败后重新 `openclaw browser snapshot`，不复用旧 ref。

## 2. 内容管理页字段

记录每条已发布视频：
- 标题/文案
- 发布时间
- 视频时长
- 可见的播放量/点赞/评论/转发/收藏等列表指标
- 审核状态（已通过/审核中/未通过）
- 是否置顶、是否加入合集

如果用户声称已发布到第 N 条，而本地文件只记录到第 M 条，以用户说法为线索进后台核验，不得直接否认。

## 3. 内容分析页字段

表格字段固定记录：
- 视频标题
- 发布时间
- 播放量
- 完播率
- 点赞
- 评论
- 转发
- 收藏
- 涨粉
- 平均播放时长
- 5秒留存率（若可见）

输出时用表格或短列表，避免长截图描述。

## 4. 账号概览字段

记录统计周期和：
- 播放量
- 点赞数
- 评论数
- 转发数
- 收藏数
- 净涨粉
- 主页访客
- 视频发布数
- 平均完播率
- 平台给出的同类创作者百分位（若可见）

## 5. 粉丝数据字段

记录：
- 总粉丝数
- 新增粉丝数
- 流失粉丝数
- 粉丝画像（性别/年龄/地域分布，若可见）
- 活跃粉丝列表（只记录昵称和互动次数，不展开隐私信息）

## 6. 复盘判断顺序

优先级：
1. 完播率
2. 评论
3. 播放量
4. 点赞
5. 转发

补充观察：
- 主页访客
- 净涨粉
- 播放 → 关注转化

结论映射：
- 完播率高、评论高：内容结构和钩子有效，继续放大。
- 完播率高但涨粉低：内容能留人，但缺少关注理由——补人设标签、系列预告、主页引导。
- 完播率低：先改前3秒钩子和视频节奏。
- 播放量高但完播率低：推荐给了但留不住人，必须优化内容节奏。
- 转发高但评论低：内容有传播价值但缺少讨论入口，补互动钩子。
- 纯人设内容低效：不要只改文案，必须换真实具体故事或降频。

## 7. 输出格式

必须包含：
- 数据来源与核对时间
- 账号概览
- 单条内容分析表
- 粉丝数据
- 最大优势
- 最大短板
- 下一步动作

若无法登录或后台不可访问，只报告阻塞，不用本地草稿推断真实数据。

# DY 发布频率管理

本文件定义发布节奏控制策略，包括新账号 warm-up、日常发布上限、频率联动健康度。目标是避免高频发布触发平台"营销号"判定。

## 0. 总原则

- 发布频率是封号高危信号之一，新账号尤其敏感。
- 抖音对发布频率的容忍度略高于小红书，但新账号仍需养号。
- 默认不自动点击"发布"按钮——即使频率允许，也保留人工确认环节。
- 发布节奏由账号健康度和账号年龄共同决定，不是用户要发就发。

## 1. 账号阶段分级

| 阶段 | 判定条件 | 日发布上限 | 说明 |
| --- | --- | --- | --- |
| 新生期 | 注册 < 14 天 | 1 条/天 | 极度保守，优先养号而非发量 |
| 成长期 | 注册 14-60 天 | 2 条/天 | 逐步建立内容结构 |
| 稳定期 | 注册 > 60 天 + 近 30 天有稳定互动 | 3 条/天 | 可正常运营节奏 |
| 恢复期 | 曾被限流后恢复 | 1 条/2 天 | 降速运营，观察恢复情况 |

## 2. Warm-up 策略（新账号专用）

### 2.1 前 7 天养号行为

| 天数 | 建议行为 | 避免行为 |
| --- | --- | --- |
| D1-D2 | 浏览推荐流、搜索感兴趣话题、点赞 3-5 条、完整观看 5-10 条视频 | 不发视频、不评论、不关注 |
| D3-D4 | 继续浏览+点赞、收藏 2-3 条、关注 2-3 个账号 | 不发视频、不评论 |
| D5-D6 | 浏览+互动、开始少量评论（每天 1-2 条，纯正常用户口吻） | 不发视频 |
| D7 | 可尝试第一条视频（非争议内容，建议15-30s短视频） | 不连续发视频 |

### 2.2 Warm-up 注意事项

- 养号期间的浏览和互动行为也要遵循 `dy-anti-ban-rules.md` 的行为随机化。
- 观看视频时要模拟完播行为（停留到视频结束），不要立即划走。
- 点赞和收藏不要集中在同一类内容，模拟真实兴趣分布。
- 不要在养号期间用 Viral Copy 或选题灵感生成的文案发布。
- 养号完成后，第一条视频优先选择"低争议、高实用"的话题。

## 3. 日常发布节奏控制

### 3.1 发布前频率检查

```
1. 读取知识库 actions/ 中最近 24 小时的发布记录
2. 统计今日已发布数量
3. 对照当前账号阶段的日发布上限
4. 如果已达上限 → 提示用户"今日已达发布上限（x/上限）"，不继续
5. 如果接近上限（上限-1）→ 提示"今日仅剩 1 次发布额度"
```

### 3.2 发布间隔控制

| 场景 | 最小间隔 | 说明 |
| --- | --- | --- |
| 同日连续发布 | 30-60 分钟 | 随机间隔，不要整点发 |
| 连续发布同主题 | 2 小时以上 | 避免被判定批量内容 |
| 发布后立即评论回复 | 15 分钟以上 | 发布和互动行为不连发 |

### 3.3 发布时间建议

参考知识库中历史发布效果数据（参见 `dy-effect-tracking.md`），优先在历史高互动时段发布：

- 如果知识库有足够数据，选择历史平均互动最高的时段。
- 如果没有历史数据，默认建议：午间 11:30-13:00、晚间 18:00-22:00。
- 抖音晚间流量高峰通常比小红书更集中在 19:00-21:00。
- 不要在凌晨 2:00-6:00 发布——这是异常活跃时段，容易被标记。

## 4. 健康度联动

| 健康度 | 发布策略 |
| --- | --- |
| 健康 | 按阶段上限正常发布 |
| 观察 | 发布频率降速 50%，每次发布前必须人工确认 |
| 限流 | 禁止发布，只允许分析和评论回复 |
| 异常 | 全部停止 |

## 6. 多日发布计划（可选）

当用户要求批量发布时，不要一次性排满，而是给出分日计划：

1. 先检查当前剩余额度和健康度
2. 按每天上限拆分发布计划
3. 每天之间间隔至少 8 小时
4. 输出日历式计划表给用户确认
5. 每天发布前重新检查健康度

## 7. 失败降级

- 发布频率检查失败（知识库不可读）→ 保守默认为"今日已发 1 条"，限制为 1 次/天
- 健康度检查失败 → 不发布，提示用户先完成健康检查
- 发布间隔不足 → 排队等待，提示用户预计可发布时间
